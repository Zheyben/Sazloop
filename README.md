# SalvemosLaComida

Proyecto final del curso Desarrollo Web Integrado.

SalvemosLaComida es el nombre provisional de una plataforma web para reducir el desperdicio alimentario mediante la publicación y reserva de packs sorpresa ofrecidos por establecimientos afiliados.
