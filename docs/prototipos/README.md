# Prototipos del primer avance

La solución se diseñará con enfoque mobile-first. El primer avance exige como mínimo un formulario o pantalla funcional por integrante, sin contar login ni funciones de seguridad.

## Pantallas mínimas propuestas

| Participante | Pantalla o formulario | Función que demuestra |
|---|---|---|
| Emanuel | Solicitud de afiliación y carga de documentos | Registro de un establecimiento. |
| Daniel | Publicación de oferta y variantes | Configuración de tamaños, precios, stock y horario. |
| Franco | Confirmación de recojo | Búsqueda y validación del código. |
| Piero | Búsqueda y detalle del pack | Filtros, información, alérgenos y restricciones. |
| Alejandro | Reserva y pago simulado | Selección de variante, cantidad y medio de pago. |

También pueden diseñarse pantallas adicionales como panel empresarial, revisión administrativa o reseña.

## Reglas visuales

- Diseñar primero para el ancho de un celular.
- Utilizar navegación y botones fáciles de tocar.
- Mostrar mensajes comprensibles.
- Identificar pagos, boletas y funciones simuladas.
- Marcar como “Próximamente” cualquier función futura.
- Mantener los mismos nombres del glosario y los requisitos.

## Archivos

Se conservará el archivo editable y una exportación visible de cada prototipo.
