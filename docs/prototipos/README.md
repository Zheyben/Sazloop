La sección 3.6 del informe contiene cinco pantallas elaboradas mediante Google Stitch. Corresponden al mínimo de cinco pantallas no relacionadas con login/seguridad para el equipo. Son prototipos de Sazloop, no evidencia de un frontend implementado.

| Pantalla visible | Relación con los RF |
|---|---|
| Solicitud de afiliación | RF-04, RF-05, RF-06 |
| Gestión y publicación de oferta | RF-11, RF-12, RF-13 |
| Búsqueda de packs | RF-14, RF-15 |
| Reserva y pago simulado | RF-16, RF-20 |
| Confirmación de recojo | RF-21 |

Las pantallas usan el nombre Sazloop. GPS y delivery aparecen como funciones futuras, no activas. Los prototipos documentan el diseño del avance 1; la implementación de la interfaz se refleja por separado en el [estado actual](../tareas/ESTADO_ACTUAL.md).
